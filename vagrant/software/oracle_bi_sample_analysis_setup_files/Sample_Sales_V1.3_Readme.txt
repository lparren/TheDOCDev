----------------------------------------------------------------------
1.  DATASET INSTALL
----------------------------------------------------------------------

   === V1.3 Dataset is unchanged compared to earlier releases. If you 
   already have Sample Sales installed, you may skip this update. ===

   1.1 To install dataset, unzipp all xml files from 
   Sample_Sales_V1.3_Dataset.zip into your local OBI EE install subdirectory :
	..\OracleBI\server\Sample\samplesales\*.*

   1.2 To activate alternative products or region datasets : replace 
   original Product.xml or Market.xml data files with selected file 
   from included choices in alternative sets folders. Make sure you 
   rename selected file to exactly Product.xml or Market.xml (you may 
   keep a backup copy of original generic xml file).
   Restart OBI EE server to see the changes.

----------------------------------------------------------------------
2.  RPD INSTALL
----------------------------------------------------------------------
   2.1 To install RPD, copy Samplesales.rpd file into your local OBI 
   EE RPD subdirectory : ..\OracleBI\server\RPD\

   2.2 Update [REPOSITORY] section of CONFIG.INI file with 
	Star	= samplesales.rpd, DEFAULT;

   2.3 Verify that value of Repository variable BI_EE_HOME into RPD is
   set to correct drive on your local install. Default is 'd:\OracleBI'
   Change this to the correct settings. To update this, open RPD 
   (Administrator/Administrator), navigate to >Manage>Variables, click
   Repository>Variables, then double click on variable BI_EE_HOME and 
   update to correct value.


----------------------------------------------------------------------
3.  WEBCAT INSTALL
----------------------------------------------------------------------
   3.1 To install Webcat unzip all files from :
   Sample_Sales_V1.3_Webcat.zip
   into your local OBI EE Catalog subdirectory :
	..\OracleBIData\web\catalog\Samplesales\
   Note, the content of the directory above should be exactly
	File  Root.atr
	Foder \Root

   3.2 Update <CatalogPath> section of instanceconfig.xml file in your 
   install with : "YOURDRIVE"/OracleBIData/web/catalog/Samplesales
